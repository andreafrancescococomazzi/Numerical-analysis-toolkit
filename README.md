# Numerical Analysis Toolkit

A Python toolkit for implementing and comparing numerical analysis algorithms.

## Features

- Interpolation using linear splines, cubic splines, and global polynomials.
- Least-squares approximation using LU and QR methods.
- Eigenvalue and eigenvector computation.
- Root finding with Newton's and secant methods.
- Comparison between equally spaced and Chebyshev nodes.

## Technologies

Python, NumPy, SciPy, Matplotlib.

## Goal

To compare the accuracy, residuals, and numerical stability of different methods.
